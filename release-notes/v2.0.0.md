# v2.0.0 — App Store metadata audits and verified fixes

Version 2 extends the app-store-review skill from source-code review to local and connected App Store metadata review. Existing code-only workflows continue to work without ASC or Apple credentials.

- Audit supplied metadata exports, text, and screenshots offline, or connect to a selected app/platform/version through the optional Rork ASC CLI.
- Guide installation and authentication only when needed, preserve existing profiles, check command compatibility, and resolve exact resource IDs before collection.
- Report evidence, affected fields/locales, confirmed issues, items needing verification, optional improvements, and gaps in coverage.
- Have the user's local agent prepare text corrections with its file tools, inspect an ASC dry-run, apply authorized changes, and fetch the actual result. The agent compares current values with the original and proposed values before writing, preserving concurrent edits and unrelated fields.
- Handle partial updates without replaying an entire export. Provide guided paths for review notes, categories, age declarations, screenshots, and manual-only resources.
- Keep the ATT, web account-deletion, and logging false-positive corrections from v1.3.2.

## Setup and migration

Keep your existing skill/plugin installation. Code reviews and local audits need no ASC account. Connected workflows require a compatible Rork `asc` installation and access to the selected app. Command recipes were checked against 1.5.4 (a29ab94); agents check installed help for version-specific capabilities. There are no bundled runtime scripts or Python requirements for skill users.

Existing credentials and agent configuration are reused. The workflow does not require installing another skill pack or initializing global/project agent files. Audit requests do not authorize remote edits; submission and release are separate actions. Optional network access is now documented explicitly.

## Initial write scope

The main text workflow covers nonempty field updates in existing localizations. Locale addition/deletion, field clearing, declarations, and media replacement use separate reviewed procedures. Privacy-label coverage depends on the installed CLI/API; unavailable data remains an explicit manual verification item. No workflow guarantees App Review approval.

## Validation

Maintainer tests check release packaging, bundled references, and the no-network ASC simulator. The optional installed-ASC check validates synthetic fixtures offline. CI runs these tests on Linux, macOS, and Windows with Python 3.10 and 3.13; this is development tooling only. Independent agent evaluations exercise the actual instructions, including coverage gaps, scoped corrections, preservation of unrelated text, and recovery from partial writes. Prompts, evaluator criteria, and recorded outcomes are included in `tests/scenarios/`.
